# Security policy

## Reporting a vulnerability

Please do not publish exploit details or private message content in a public
issue. Until a private repository security contact is configured, contact the
repository owner through GitHub's private contact options and include only the
minimum information needed to reproduce the issue. Do not include real SMS
content, credentials, or signing material.

DEG Messages is an SMS client, not an end-to-end encrypted messaging service.
SMS delivery and storage are controlled by Android and the mobile carrier.
Recycle Bin copies are stored in app-private local storage and are not
separately encrypted by the app.
