# Changelog

## 2.3.3

- Updated the conversation layout for keyboard changes and long phone numbers.
- Added one-tap SIM switching, remembered conversation SIMs, and incoming SIM filters.
- Added independent action ordering for conversation and message menus.
- Hardened notification entry, OTP clipboard handling, attachment selection, and backup validation.
- Updated Gradle to 9.9.2 with a pinned distribution checksum and versioned GitHub Actions commits.

## 2.3.0 — 2026-11-21

- Fixed the reply composer layout and single-message deletion from a conversation or the OTP tab.
- Added bundled sender logos, additional OTP lengths and message highlights, and improved archive and category navigation.

## 2.2.0 — 2026-11-20

- Added dual-SIM selection, scheduled SMS, and outgoing photo and short-video MMS with carrier-aware attachment limits.
- Added inbox categories, advanced search, local spam protection, and editable quick replies.
- Added one-touch copying of highlighted links, phone numbers, OTPs, and email addresses by long press.
- Added a PIN or password lock with optional fingerprint verification and manual message backup and restore.
- Redesigned settings and action sheets, added optional navigation bar transparency, and introduced paginated conversation history.

## 1.0.0

- Initial public release with SMS, OTP tools, notifications, archive, spam rules, and a local Recycle Bin.
