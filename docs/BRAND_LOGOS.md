# Offline SMS brand logos

DEG Messages matches the SMS sender header against its bundled directory. Indian carrier prefixes and category suffixes are parsed separately from the header. The displayed sender ID remains available, and the directory does not affect spam decisions, verification, or conversation grouping.

Most aliases come from the [TRAI compiled list of SMS headers](https://trai.gov.in/node/7411). The catalog includes a small number of additional exact aliases, including Zepto IDs observed on-device. [TRAI’s Header Information Portal](https://www.trai.gov.in/portal-and-apps) is the reference for checking future additions. The bundled directory is a snapshot and has no runtime downloads.
