# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful, and harassment-free project space
for everyone, regardless of experience, identity, background, or viewpoint.

Examples of unacceptable behavior include harassment, insults, personal
attacks, discriminatory language, publishing another person's private
information, and disruptive conduct in project spaces.

Project maintainers may remove or reject contributions that violate this code
and may restrict participation when needed to protect the community. Report
concerns privately to the repository maintainers. A contact address will be
listed here when the public repository is established.
